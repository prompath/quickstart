# COIN-OR Branch and Cut Solver

Great slides for reference: [Here](https://www.cs.upc.edu/~erodri/webpage/cps/theory/lp/milp/slides.pdf)

The algorithm uses LP solving techniques to solve for the optimum point. The keyword is LP relaxation. If the optimum point does not satisfies the integral constraints, the sub-problems are then formed. The sub-problems are made from the main problem.
