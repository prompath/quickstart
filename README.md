# Quick Start
ML project quick starts. This repo should help me freshen up when I need to develop an ML project. For a certain topic, the contents should be
- A quick technical overview in the README.
- A sample dataset. This doesn't have to be raw. A preprocessed and ready-to-use one should be fine.
- The algorithm running script.
- (Optional) A running pipeline. Maybe in the form of simple argparse script.
